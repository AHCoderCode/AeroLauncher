# AeroShell Desktop 0.7.0 portable bundle

AeroShell Desktop 0.7.0 is distributed as a portable ZIP, not an installer.

1. Download the **AeroShell-Windows-v0.7.0** artifact from the successful GitHub Actions run.
2. Save the downloaded artifact ZIP in Downloads.
3. Right-click it and select **Extract All**.
4. Review and scan the outer artifact ZIP with Windows Security.
5. Open the extracted folder. It contains the versioned release ZIP and its SHA-256 checksum file.
6. Scan the release ZIP, then extract it into a normal user folder such as Documents\AeroShell.
7. Scan the extracted folder and AeroOS.Windows.exe with Windows Security before considering launch.

The application targets Windows 10 x64 and .NET Framework 4.8. It is unsigned. A successful compile, static source checks, or a matching checksum do not establish that a file is malware-free. Do not bypass Microsoft Defender or SmartScreen warnings. If either blocks the app, stop and have a trusted adult review the detection. Cancel if an unexpected administrator/UAC prompt appears; AeroShell should run as a normal user.

AeroShell starts maximized with normal Windows minimize, maximize/restore, resize and close controls. Use the title-bar close button, taskbar Exit control or Alt+F4 to close it and reveal the normal Windows desktop.

## Navigation

- **Desktop:** one-click shortcuts to common apps and folders.
- **All apps:** search, launch, pin and unpin Start Menu apps.
- **Files & folders:** open Documents, Downloads, Pictures, Music, This PC and Recycle Bin in real Windows File Explorer.
- **Personalization:** choose dark/light appearance, accent colour, reduced effects and an AeroShell-only wallpaper.
- **Start:** open with the Start button or Ctrl+Space.

Keyboard shortcuts: Ctrl+1 Desktop, Ctrl+2 All apps, Ctrl+3 Files & folders, Ctrl+4 Personalization, Ctrl+, Personalization, Escape closes Start, and Alt+F4 exits AeroShell.
